# CSS Units Box Model Fonts Task

## Description
This project demonstrates the use of HTML and CSS to create a responsive webpage using viewport units, box model properties, gradients, and font styling. The webpage contains an image section and a styled button aligned according to the given layout requirements.

## Project Structure
project-folder/
index.html  
style.css  
README.md  

## How to Run
1. Download or save the project folder.
2. Make sure index.html and style.css are in the same folder.
3. Open index.html in any web browser.

## Features
- Responsive layout using viewport units
- Equal spacing from left and right side
- Top spacing using viewport height
- Gradient styled button
- Proper use of box-sizing
- Image fitted properly using object-fit
- Clean and simple UI
- No scrolling issue
- No use of Flexbox
- No use of overflow hidden
- No use of relative or absolute positioning

## Technologies Used
HTML5  
CSS3  

## CSS Concepts Used
- Viewport Units (vw, vh)
- Box Model
- Box Sizing
- Linear Gradient
- Object Fit
- Margin and Width Management

## Output
When opened in the browser, the page displays:
- A centered image section
- Equal spacing from left and right
- A gradient button below the image
- Responsive layout without scrollbars
